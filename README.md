# PandelisZ/homebrew-tap

## Codex Remote

```bash
brew install --cask pandelisz/tap/codex-remote
```

[Codex Remote](https://codexremote.io) — a macOS menu bar app that provisions cloud machines
and wires them up as remote Codex and Claude Code agents.

## vci

```bash
brew install pandelisz/tap/vci
```

[vci](https://github.com/PandelisZ/cryptographically-verifiable-ci-runner) — run a test once, sign
what it depended on, and let CI skip it. macOS and Linux. `Formula/vci.rb` is generated by vci's
release workflow on each tag; do not edit it by hand.
